【题目1】请通俗说明 AI Agent 的定义，以及与传统对话机器人、普通 RAG 问答机器人的核心差异。
候选人回答：传统对话机器人是“你问它答”；普通 RAG 问答是“先查资料再回答”；AI Agent 会围绕目标拆解任务、调用工具、检查结果并继续执行。
考察目的：核实候选人基础认知，区分新手与实操型技术人员。
参考答案：Agent 具备目标驱动、任务规划、工具调用、状态记忆和基于反馈迭代行动的能力。
得分：8/10
评分依据：概念区分准确，能说明目标驱动和工具调用，案例深度略可加强。

【题目2】Agent 常见的 ReAct 与 Plan-and-Execute 规划方式有什么区别？生产环境如何避免循环执行？
候选人回答：ReAct 每一步边思考边行动，灵活但可能反复试错；Plan-and-Execute 先生成计划再执行，便于审计但计划可能失效。生产上会设置最大步数、预算和超时，并用状态机与结果验证器判断终止。
考察目的：考察规划、反思与任务终止控制能力。
参考答案：比较两种规划模式，并用最大步数、预算、超时、显式状态和验证器控制循环。
得分：8/10
评分依据：能比较两类模式并给出多层终止保护，缺少线上故障案例。

【题目3】请说明 RAG 的核心流程，并给出两个提高检索召回率的工程手段。
候选人回答：流程包括文档解析、分块、向量化、索引、查询改写、召回、重排和生成。提高召回可以增加关键词与向量混合检索，并优化分块和元数据过滤。
考察目的：考察知识库构建、检索与生成链路。
参考答案：覆盖解析、分块、嵌入、索引、召回、重排和生成；可采用混合检索、查询改写、元数据过滤等手段。
得分：7/10
评分依据：主流程正确，优化手段有效，但对评估闭环说明较少。

【题目4】在 Agent 中接入 MCP 工具时，如何设计工具边界与最小权限控制？
候选人回答：每个 MCP 服务只暴露完成任务必需的工具，按用户和任务做最小权限授权；高风险写操作需要参数校验、二次确认和审计日志，敏感凭证放在服务端密钥管理中。
考察目的：考察工具协议理解、权限控制和生产安全意识。
参考答案：按职责拆分工具，最小权限、输入校验、人工确认、审计和密钥隔离。
得分：9/10
评分依据：覆盖权限、确认、审计和密钥隔离，安全设计完整。

【题目5】如何评估一个 AI Agent 是否适合上线？请给出指标和灰度发布方案。
候选人回答：先构建真实任务集，评估成功率、工具调用正确率、事实一致性、延迟和成本；上线前做离线回归和红队测试，再按用户比例灰度，监控失败率和人工接管率。
考察目的：考察评估、可观测性与生产发布能力。
参考答案：使用任务成功率、工具调用准确率、事实性、安全、延迟和成本指标，并结合离线评测、灰度和监控。
得分：8/10
评分依据：指标和灰度路径完整，缺少具体阈值示例。
